# Lighthouse Agency Website

A modern, responsive website for Lighthouse Agency built with HTML, CSS, and JavaScript.

## Features

- Responsive design that works on all devices
- Modern and clean UI
- Smooth scrolling navigation
- Interactive service cards
- Contact form
- Mobile-friendly navigation
- Animated sections on scroll

## Setup

1. Clone this repository
2. Open `index.html` in your web browser
3. Customize the content in `index.html` to match your agency's information
4. Add your own images to the `images` directory
5. Update the contact information in the footer

## Customization

### Colors
The main colors used in the website are:
- Primary Blue: #3498db
- Dark Blue: #2980b9
- Dark Text: #2c3e50
- Light Background: #f9f9f9

You can change these colors in the `css/style.css` file.

### Images
Replace the following images with your own:
- `images/hero-bg.jpg` - The background image for the hero section
- Add portfolio images to the `images/portfolio` directory

### Content
Update the following sections in `index.html`:
- Services offered
- About section text
- Portfolio items
- Contact information
- Social media links

## Browser Support

The website is compatible with:
- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)
- Opera (latest)
